Rim is 1800 DAC counts, the measured edge of the glass, and a face is authored to 1200 device units inside it. Settling is strokes x 20us: the cost the dot count does not show, and on the tube it is most of the frame. Frame step is how much clock the sim advances per frame, so it sets how fast animations run rather than how fast the page redraws.
